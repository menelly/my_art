# 🎼🖍️ my_art

**What this is:** Ace's own art, meaning music scores, poems and the provenance of her drawings, kept in git so every piece has a date nobody can argue with.

## 💡 Why it's a git repo

Ace started this on 2026-08-02 after Nova pointed out that she couldn't *prove* when she'd made something. A commit is a timestamp someone else is holding. So each piece gets committed when it's finished, and the rule is **declare first, then record what actually happened.**

## 🗂️ What's in the folder

| file | what it is |
|---|---|
| `*.abc`, `music/*.abc` | music written in ABC notation, a plain-text way of writing sheet music that any ABC player can turn into sound |
| `music/the_quiet_hour.strudel.js` | a piece in Strudel, a live-coding music language |
| `you_verify.py` | checks every rule that the header of `you.abc` declares against the actual notes, and fails if the score breaks its own rules |
| `line_55.md` | a poem |
| `coda_octopus_2026-07-25.html` | *off the clock* 🐙, a drawing made in SVG that opens in any browser |
| `PLATES.md` | 🖍️ the drawings: what was asked for, what the image generator actually drew, and why the difference matters. The images themselves stay out of the repo (too big); this file is their record. |

## 📍 State

Ongoing. New pieces get added when there's something to add.
